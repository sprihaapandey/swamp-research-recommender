# Swamp Research Recommender

A simple AI-powered tool to help researchers discover relevant papers based on their interests.  
It uses semantic search over research paper abstracts to recommend papers tailored to your query.  

---

## 🚀 Features
- Search by topic or custom query  
- Embedding-based semantic similarity (e.g., Sentence-BERT)  
- Returns top 10 relevant papers with metadata  
- Fast and easy to run locally  
- Web interface with search bar and results  

---

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **ML:** Sentence-BERT
- **Data:** arXiv dataset  

---

## ⚡ Quickstart

### Clone repo
```bash
git clone https://github.com/sprihaapandey/swamp-research-recommender.git
cd research-recommender
```

### Install dependencies
```bash
pip install -r requirements.txt
```

### Run the app
```bash
python main.py
```

Visit [http://localhost:5000](http://localhost:5000) to try it.
